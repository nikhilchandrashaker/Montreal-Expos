# Montréal Expos Statistical Database (1969–2004)

A tribute site and workbook for the Montréal identity of the franchise. Washington Nationals years (2005 onward) are excluded.

## Files
- `montreal_expos_definitive_stat_database.xlsx` — Seasons (W-L%, Pythagorean W-L%, run differential, totals as live formulas), Manager Splits, Managers (SUMIF from the splits), Leaders, Timeline, Facts, Sources
- `montreal-expos-tribute.html` — standalone site, light and dark mode

## Scope notes
- All 36 seasons are checked against the published franchise record of 2,755–2,943–4.
- Leaders only rank players whose full franchise totals fall inside 1969–2004. The source merges Expos and Nationals totals.
- Not yet included: pitching leaders, draft, all-time roster, All-Stars, React component.

## Sources
Baseball-Reference franchise history and Top 50 leaders, Baseball-Reference Bullpen, ESPN.com.
